## 1. 한 줄 요약

**당사는 "얼굴에 안경을 정확히 얹어 실시간으로 따라가게 만드는 엔진과 그 엔진을 감싼 화면 없는 클라이언트"를 납품한다.** 그 위에 씌우는 화면, 그 뒤에 붙는 서버, 그리고 상품 데이터는 발주사 몫이다.

---

## 3. 책임 분담 (RACI)

R = 실행 · A = 승인 · C = 협의 · I = 통보

| 활동 | 당사 | 발주사 |
|---|---|---|
| 요구사항 확정 | R | A |
| 공용 코어·정합 엔진 개발 | R | I |
| 웹 클라이언트 개발 | R | I |
| 안드로이드 하이브리드 셸 개발 | R | C |
| UI/UX 디자인 | C | R, A |
| 디자인 적용(퍼블리싱) | C | R |
| 제품 마스터 API 규격 작성 | R | A |
| 제품 마스터 서버 구현 | C | R |
| 3D 에셋 규격 작성 | R | A |
| 3D 에셋 제작 | C | R |
| Play Store 등록·심사 대응 | C | R |
| PD 기준값 수집(피험자 섭외) | C | R |
| 검수·인수 | C | R, A |

## 4. 전제 조건

아래가 충족되지 않으면 해당 작업은 **일정에서 제외되고 납기가 이동**한다. 각 항목의 기한은 [05 일정·마일스톤](05-일정-마일스톤.md)에 기재했다.

| # | 전제 | 미충족 시 영향 |
|---|---|---|
| P-1 | 발주사가 제품 마스터(프레임 사양) 자료를 W2 종료 전 제공 | 샘플 1종으로만 검수. 다품종 전환 로직 미검증 |
| P-2 | 발주사가 3D 에셋(GLB) 또는 제작 일정을 W4 종료 전 확정 | 절차적 폴백 프레임으로만 검수. 외관 평가 불가 |
| P-3 | 발주사가 UI 디자인 산출물을 W7 종료 전 제공 | 피팅 뷰 단독(디자인 미적용) 상태로 납품 |
| P-4 | 발주사가 HTTPS 호스팅 환경(도메인·인증서)을 W8 종료 전 제공 | 당사 임시 호스팅으로 검수, 운영 배포는 발주사 책임 |
| P-5 | 발주사가 Play Store 개발자 계정과 등록 권한을 W8 종료 전 제공 | APK/AAB 파일 납품까지만. 스토어 등록 제외 |
| P-6 | 검수용 타깃 안드로이드 기기 1대 이상 대여 또는 모델명 확정 | 당사 보유 기기 기준으로만 성능 검수 |
| P-7 | PD 기준값 측정 협조(피험자 및 동공거리계) | PD 정확도 수용 기준을 "내부 반복성"으로 대체 — [06](06-검수기준서.md) §4 참조 |

## 5. 변경 관리

| 구분 | 처리 |
|---|---|
| 경미한 변경 | 합의된 요구사항의 표현·배치 조정. 일정 영향 없으면 이슈 트래커 기록 후 즉시 반영 |
| 범위 변경 | 신규 FR 추가, 수용 기준 상향, 지원 대상 확대. **공수 재산정 후 서면 합의** 전까지 착수하지 않음 |
| 제외 항목의 편입 | §2 "제외" 열의 항목은 본 계약 범위 밖. 필요 시 별도 계약 |

범위 변경 요청은 [08 커뮤니케이션·산출물 규격](08-커뮤니케이션-산출물규격.md)에 정한 채널로만 접수한다. 구두 요청은 이슈로 등록된 시점부터 유효하다.
