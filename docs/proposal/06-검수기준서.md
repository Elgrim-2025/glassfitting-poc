## 1. 판정 원칙

1. 모든 항목은 **측정 도구와 측정 절차가 지정**되어 있다. 지정되지 않은 방식의 측정 결과는 판정 근거가 되지 않는다.
2. 측정 기기·조건(브라우저, 해상도, 조명, 거리)을 보고서에 함께 기록한다. 조건이 다르면 같은 항목도 다른 값이 나온다.
3. "자연스러움" 같은 주관 항목은 **5점 척도 평균**으로만 판정하고, 단독으로는 반려 사유가 되지 않는다.
4. 판정 기준 플랫폼은 **중급 안드로이드 + Chrome, Standard 프로파일(1280 × 720)**이다.

## 2. 측정 도구

| 도구 | 제공 | 측정 대상 |
|---|---|---|
| 디버그 HUD | 화면 내 계기판 | 정점간 거리, 패드 간격, 관통 잔여, 전방 보정, 지터, 모션 지연, FPS, 검출 ms, 파이프라인 ms, 추적 유지율, 재획득 ms, PD ± 신뢰구간 |
| 지표 CSV | HUD "지표 CSV" 버튼 | 프레임별 전 지표 → 통계 분석 |
| 세션 녹화·재생 | HUD "녹화 시작/정지" | 같은 입력으로 파라미터 변경 전후 비교 |
| 골든 벡터 | `npm test` | 코어 출력 등가성(회귀 및 플랫폼 간) |
| 얼굴 변형 벤치 | `npm run bench:fit` | 얼굴 14종 × 포즈 5종 관통·부유 수치 |
| Blender 실메시 판정 | `fit_bench.py` | 실제 GLB 메시 대 얼굴 메시 부호 거리 + 렌더 |

## 4. PD 기준값을 확보하지 못한 경우

C-1 · C-2는 **동공거리계로 측정한 기준값**이 있어야 판정할 수 있다. 피험자 섭외와 계측기는 발주사 협조 사항([05 일정](05-일정-마일스톤.md) P-7)이며, 11/06까지 확보되지 않으면 아래로 대체한다.

| 원 기준 | 대체 기준 |
|---|---|
| C-1 MAE ≤ 2.0 mm | **삭제** — 절대 정확도는 판정하지 않음 |
| C-2 Bland-Altman ±3 mm | **삭제** |
| C-3 반복성 ≤ 1.0 mm | **유지** (기준값 불필요) |
| C-4 조건 민감도 ≤ 1.5 mm | **유지** |
| — | **신설**: 카드 캘리브레이션 전후 값 차이 ≤ 3 mm |

대체 적용 시 납품 문서에 **"절대 정확도는 미검증"**을 명시한다. RFP가 요구한 "참고 수준(±수 mm)"은 이 경우 보증 대상에서 제외된다.

## 5. 인수 절차

| 단계 | 내용 | 주체 |
|---|---|---|
| 1 | 당사가 §3 전 항목을 측정하고 **검수 보고서**(측정값·조건·기기 기재)를 제출 | 당사 |
| 2 | 발주사가 동일 절차로 재현 측정. HUD·CSV 사용법은 인수 교육에서 전달 | 발주사 |
| 3 | 불일치 항목은 **측정 조건부터 대조**한다 (기기·조명·거리·프로파일) | 공동 |
| 4 | 기준 미달 항목에 대해 수정 또는 기준 조정을 협의, 서면 기록 | 공동 |
| 5 | 전 항목 합의 시 인수 확정 | 발주사 |

**반려 사유가 되는 것**: §3의 기준 미달, D-1~D-4 실패.
**반려 사유가 되지 않는 것**: 측정 절차가 지정되지 않은 주관 평가, [02 과업 범위·제외 명세](02-과업범위-제외명세.md) §2의 제외 항목, 디자인 관련 지적.
